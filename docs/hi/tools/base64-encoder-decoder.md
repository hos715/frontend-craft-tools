# Base64 Encoder / Decoder

Encode text to Base64 and decode Base64 back to text directly in the browser.

## उपयोग

1. index से टूल पेज खोलें।
2. ज़रूरत के अनुसार इनपुट और विकल्प सेट करें।
3. आउटपुट कॉपी करें या फ़ाइल डाउनलोड करें।
