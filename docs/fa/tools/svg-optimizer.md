# SVG Optimizer

Clean and optimize SVG markup to reduce file size and simplify output.

## روش استفاده

1. صفحه ابزار را از index باز کنید.
2. ورودی‌ها و تنظیمات ابزار را وارد یا تنظیم کنید.
3. خروجی را کپی کنید یا فایل را دانلود کنید.
